Workflow

Three Steps to Intelligence

1
Authorize Root
Configure an explicitly authorized directory. Root validation enforces privacy boundaries before any scanning begins.
2
Bounded Scan
Traverse manifests only (npm, pip, cargo, maven, pubspec). Sensitive files (.env, .npmrc, SSH keys) are denied before read.
3
Watch & Relate
Live file system watching with debounced changes. Relationships are detected and persisted for graph visualization.
