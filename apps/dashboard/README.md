# Private Dashboard

Status: **Scaffold only. No implementation exists.**

Planned responsibilities:

- Overview from real local API data.
- Project explorer with search and filters.
- Project detail and evidence views.
- Interactive relationship graph.
- Classification, exclusions, overrides, and manual relationships.
- Scanner controls, roots, exclusions, progress, history, and errors.
- Responsive, accessible, dark-first interface.

Boundaries:

- No direct database or filesystem access.
- No production mock-data fallback.
- No private data in static assets or logs.
- Heavy views are lazy-loaded.

See [../../docs/PRODUCT_SPEC.md](../../docs/PRODUCT_SPEC.md) and [../../docs/API.md](../../docs/API.md).
